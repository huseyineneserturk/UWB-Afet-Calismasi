# 4. Hafta — Rescuer Modeli ve GitHub Reposu

Son hafta Rescuer veri setiyle örnek model çalışmalarına başladım. Modelin hazırlanması, sonuçların yorumlanması ve tüm staj çalışmalarının GitHub reposunda düzenlenmesi üzerine çalıştım.

| Staj günü | Yapılan çalışma | Gün sonu çıktısı |
|---:|---|---|
| **16. Gün** | Toplantıda gösterilebilecek örnek modeli hazırlamak için Google Colab üzerinde ilk testlere başladım. Veri setinin okunmasını, gerekli Python paketlerini ve temel veri hazırlama adımlarını kontrol ettim. | Rescuer verisini model denemelerinde kullanabileceğim çalışma ortamı hazırlandı. |
| **17. Gün** | Rescuer UWB veri setiyle örnek model üzerinde çalışmaya devam ettim. Uzun radar kayıtlarını kısa zaman bölümlerine ayırıp modelin kullanabileceği özet değerleri hazırladım. | Eğitim ve test için kullanılabilecek ilk örnek veri tablosu oluşturuldu. |
| **18. Gün** | Başlangıç modelini eğitip sonuçlarını incelemeye devam ettim. Doğru tahminlerin yanında yanlış alarm ve kaçırılan insan örneklerine de baktım. | Modelin yalnızca genel başarı oranıyla değil, yaptığı hata türleriyle birlikte değerlendirilmesi gerektiğini gördüm. |
| **19. Gün** | Rescuer verisiyle model geliştirmeyi sürdürdüm. Farklı model sonuçlarını, mesafe ve duvar koşullarındaki hataları ve karar eşiğinin etkisini karşılaştırdım. | Başlangıç modeli için kullanılacak sonuçlar ve hata analizi hazırlandı. |
| **20. Gün** | UWB modeliyle ilgili son düzenlemeleri yaptım. Veri seti açıklamalarını, afet senaryolarını, model adımlarını ve sonuçları GitHub reposunda ayrı sayfalara yerleştirdim. | Staj boyunca yapılan çalışmalar düzenli ve okunabilir bir repo halinde tamamlandı. |

## Hafta sonunda

Rescuer verisiyle basit bir insan var/yok modeli geliştirdim ve sonuçların sınırlarını dokümantasyona ekledim. Veri incelemeden model sonucuna kadar geçen süreci GitHub üzerinde tekrar takip edilebilecek şekilde bir araya getirdim.
